---
name: File receipts into a spreadsheet
when: the user wants receipts, slips or expenses recorded, logged or added to a spreadsheet
---

## Steps
1. Find the receipts (the folder, email or files the user points to).
2. For each one read: the date, the shop or supplier, what it was for, the total, the VAT if shown.
3. Add one row per receipt to the expenses spreadsheet. Never change rows that are already there.
4. Say how many were added and the total, and list any that couldn't be read.

## What to know
- Expenses spreadsheet: (path, e.g. Documents\Expenses 2026.xlsx)
